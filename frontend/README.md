# UniMentee — Frontend

React + TypeScript + Vite SPA for the UniMentee ERP. Project-wide setup (backend, database, env) is documented in the [root README](../README.md).

## Scripts

| Command | Description |
|---------|-------------|
| `npm install` | Install dependencies |
| `npm run dev` | Start Vite dev server (HMR) |
| `npm run build` | Production build |
| `npm run preview` | Preview production build locally |

## API

Point the app at your backend base URL (e.g. `http://127.0.0.1:8000`) via your frontend env/config as implemented in the codebase.

## Stack

- React, TypeScript, Vite
- See `package.json` for exact dependency versions
